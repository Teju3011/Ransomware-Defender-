# **App Name**: RansomGuard Sentinel

## Core Features:

- Security Dashboard Overview: Displays an aggregated security status for monitored endpoints, including recent alerts and a prominent 'Scan' action element to initiate scans on managed agents.
- Endpoint Management: Allows administrators to register, list, and monitor the connection status and basic details of managed security agents (endpoints) connected to the system.
- Scan Reports Viewer: Provides an interface to access and review historical scan reports from registered endpoints, detailing detected threats (file paths, types, detection times) retrieved from the backend database.
- Agent Configuration Panel: Enables remote configuration of settings for managed security agents, such as toggling active protection, setting automatic update preferences, and defining scan schedules.
- Threat Analysis Tool: Leverages generative AI to analyze logged threat events reported by agents, providing context, potential impact assessments, and suggesting informed mitigation steps for identified ransomware behavior.
- Alerts & Notification Log: Offers a comprehensive log of all real-time behavior detection alerts received from endpoint agents, including timestamps and detailed trigger information for review.

## Style Guidelines:

- Dark Mode Interface: The primary theme utilizes a sophisticated, deep desaturated blue-grey as a background, setting a tone of professional calm and cyber-secure environment. (Background: #1A1E29)
- Primary Interactive Color: A vibrant yet profound electric blue is selected to signify core actions, highlight critical information, and draw user attention effectively. (Primary: #4D7FF0)
- Accent Color: A clear, bright sky-blue serves as an accent, meticulously chosen to provide compelling contrast for interactive elements, distinct status indicators, and subtle visual cues. (Accent: #63E4F5)
- Body and Headline Font: 'Inter' (sans-serif) for its modern, clean, and objective aesthetic, ensuring exceptional readability across all user interface elements and data-rich sections of the dashboard.
- Modern Vector Icons: Utilizes crisp, geometric line-art or subtly filled icons for all navigation, status indicators, and actions. This choice ensures clarity, scalability across diverse devices, and visual harmony with the dark theme.
- Intuitive Sidebar Navigation: A persistently visible left sidebar provides streamlined access to all main sections. The central dashboard integrates a prominent 'Scan' button-like element, evoking the familiar, clean interfaces of mobile security applications. The entire layout is designed to be responsive and adapt seamlessly across various screen sizes.
- Subtle UI Transitions: Incorporates smooth, unobtrusive animations for page transitions, button interactions, and data updates. These enhancements fluidly guide the user experience without causing any distraction, focusing on performance and user engagement.
